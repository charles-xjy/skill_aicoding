# 24万㎡全面开工！北京交通大学雄安校区一期工程进入大规模建设阶段

2025-01-01 14:45:34 来源： _中国新闻网_

  汽笛轰鸣，一幅描绘雄安校区未来图景的画轴徐徐展开。2024年12月30日，北京交通大学雄安校区A组团项目开工动员大会在项目现场召开，标志着北京交通大学雄安校区一期工程进入大规模建设阶段。

  根据上级批复，北京交通大学雄安校区南区将率先启动约24万平方米建设，一期后续建设将接续展开。本次开工的A组团项目主要包括学生宿舍楼。A组团生活区以“链接”为规划理念，将居住、餐饮、运动、学习等多种功能复合，打造别开生面的中央活力学生街，营造现代大学多元共享、开放交流的生活氛围，为雄安校区未来高质量发展创造优质的育人环境。

  会上，北京交通大学党委书记陈子季宣布雄安校区A组团项目正式开工。

  校长余祖俊表示，建设雄安校区是学校深入贯彻落实习近平总书记重要指示精神和党中央重大决策部署、高质量服务国家战略需求的重要举措，也是着眼学校“下一个百年发展”迈出的关键一步，承载着全校师生的殷切期盼，将成为学校转型升级、打造未来新兴基础交叉学科的重要高地。学校将以习近平总书记重要回信精神为指引，积极践行新时代高等教育的使命与担当，以更高站位、更高标准、更高要求，全力以赴建设厚重、大气、敞亮、实用的雄安校区，助力学校向世界一流大学的目标阔步前进。

  雄安新区党工委委员、管委会副主任，教育局党组书记、局长门扬对项目开工表示热烈祝贺。他表示，雄安新区将全面支持学校雄安校区建设和创新发展，全力做好服务保障工作。

  中交建筑集团有限公司党委副书记、总经理孟祥源，北京双圆工程咨询监理有限公司董事长高玉亭分别代表参建单位发言，表示将全力以赴、密切合作，将雄安校区工程建设成为样板工程、精品工程。

  学校党委副书记、纪委书记王文文，党委副书记姚念龙，党委常委、副校长施先亮等领导出席大会。党委常委、副校长李国岫主持大会。
