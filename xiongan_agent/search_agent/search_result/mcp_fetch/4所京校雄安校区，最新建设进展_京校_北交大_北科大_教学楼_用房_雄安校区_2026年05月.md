**第一站**

**北京交通大学**

北京交通大学（简称“北交大”）雄安校区占地面积约2600亩，建筑面积近200万平方米，分两期建设，一期建成以后可以容纳近20000名学生，二期建成以后将承载36000名学生。

8月28日，北交大雄安校区学生宿舍A标段项目6号楼（博士生公寓）实现主体结构封顶。A标段总建筑面积12.8万平方米，共7栋学生宿舍楼，于2024年12月30日开工建设。本次封顶的6号楼（博士生公寓）地下一层，地上七层，建成后可为约300名博士生提供住宿条件。

北交大雄安校区建设现场。赵小玉 摄

8月24日凌晨，北交大雄安校区学生宿舍B标段项目1号宿舍楼1段顶板浇筑完成，正式冲出“正负零”，进入地上主体结构施工。B标段总建筑面积11.6万平方米（地上10.17万平方米，地下1.44万平方米），主要包括5栋宿舍楼、1栋留学生公寓。

8月11日，北交大雄安校区一期第二组团项目开工，标志着雄安校区进入全面建设的新阶段。

一期第二组团项目位于雄安校区南区，预计2027年初完工，主要建设思源楼、天佑会堂、实践教学媒体中心、双创及就业指导中心、南区生活配套（食堂、学习中心、综合运动中心）、校友之家、学科学院楼及公共教学楼等22栋建筑单体，约20万平方米（其中地上约14.1万平方米、地下约5.8万平方米）。

北交大雄安校区设计鸟瞰图。资料图

其中思源楼位于校园南区的核心位置，总建筑面积约4.3万平方米，以“思源致远，未来之窗”为设计理念，由4根“巨柱”支撑起顶部通透的开放空间，造型方正、稳重有力。思源楼将于2026年9月基本完成主体结构建设，为北交大130周年校庆献礼。

北交大雄安校区一期第一、第二组团项目建筑单体共35栋、建筑面积约44万平方米，已全部开工建设，一期第三组团项目力争于今年年底开工。2026年9月，北交大雄安校区的宿舍楼将具备学生入住条件。

**第二站**

**中国地质大学（北京）**

中国地质大学（北京）（简称“地大”）雄安校区总占地面积1600亩，建设用地1200亩，总办学规模为20000人，分两期建设，其中一期工程总建筑面积51.89万平方米，满足10251名疏解学生的基本办学及科研平台的建设需求。

一期工程共分四个组团，预计2026年12月竣工，2027年9月雄安校区开办运行，完成一期疏解任务。

中国地质大学（北京）雄安校区主体工程建设启动会现场。人民网记者王红 摄

2024年8月，地大雄安校区主体工程建设启动会举行，标志着其雄安校区拉开大规模建设序幕。

首开项目总建筑面积2.93万平方米，包括1栋后勤楼和1栋本科宿舍楼。其中宿舍楼包含464间本科宿舍，可满足1800余名学生的住宿需求。

第一组团项目总建筑面积13.75万平方米，2025年4月正式开工；第二组团项目总建筑面积约20.01万平方米，计划2025年9月开工；第三组团项目总建筑面积约15.21万平方米，目前在报批阶段。

**第三站**

**北京科技大学**

北京科技大学（以下简称“北科大”）雄安校区占地面积约2450亩，建设用地约1700亩，计划分两期建设，建成后将满足约3.6万名学生学习生活的需要。

![](https://static.ws.126.net/163/frontend/images/2022/empty.png)

打开网易新闻 查看精彩图片

[北科大](https://news.163.com/news/search?keyword=%E5%8C%97%E7%A7%91%E5%A4%A7)雄安校区效果图。北科大供图

8月20日，北京科技大学雄安校区第二组团项目学科用房A、B和主校门、办公服务中心组团开工建设。

主校门位于燕赵大街北侧，坐北朝南，外观沿用北科大学院路校区传统风格的大门；学科用房A、B分列主校门两侧，总建筑面积53364平方米，建成后将承担相关学科建设功能，设置办公及实验教学条件，其外观延续学院路校区主楼经典元素，用建筑的语言打造师生校友熟悉的校园记忆符号。

办公服务中心组团坐落于雄安校区中轴“钢铁脊梁”上，总建筑面积23610平方米，由办公服务中心、教师创新坊、钻石报告厅三栋建筑构成。

7月26日，雄安校区第二组团主[教学楼](https://news.163.com/news/search?keyword=%E6%95%99%E5%AD%A6%E6%A5%BC)及学科用房C、D开工，项目总建筑面积89688平方米，预计2027年初完工。

主教学楼将承担学校基础课程教学、通识教育及大型学术活动功能，配备智慧教室、录播教室、艺术设计教室、研讨室等现代化教学设施，学科用房C、D将承担相关学科建设任务，设置办公及实验教学条件。

北科大雄安校区建设现场。北科大供图

北科大雄安校区第二组团项目总建筑面积约81.5万平方米，将建设包括主教学楼、图书馆、学生宿舍、食堂、学科用房、主体育馆、游泳馆、基础实验楼及相关配套设施等54栋建筑单体，分布于雄安校区南地块和中地块，所有标段计划在9月底前全部开工建设。

此外，北科大雄安校区首开项目中的实验实习保障中心项目已于2024年通过竣工质量验收；一期工程第一组团项目于2024年12月16日开工建设，计划2025年11月实现主体结构全部封顶，2026年9月竣工，总建筑面积约8.3万平方米，包含钢铁书院、综合楼、4栋学生宿舍楼等；一期工程第三组团总建筑面积约4.4万平方米，可研报告已报国家发改委评审。
