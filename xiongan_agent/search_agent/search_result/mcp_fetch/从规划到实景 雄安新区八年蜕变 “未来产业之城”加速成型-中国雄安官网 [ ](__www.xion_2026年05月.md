# 从规划到实景 雄安新区八年蜕变 “未来产业之城”加速成型

2025-05-31 10:59:10 来源： _央视新闻客户端_

  雄安新区建设已经走过了八个年头，八年前，雄安新区可以说是一张“白纸”，经过八年来的精心描画、着色，雄安这座“未来之城”拔节生长、稳步成形。其中，186家专精特新“ 小巨人”、独角兽、制造业单项冠军等重点领域企业落地入驻雄安新区中关村产业园，一座充满活力的“未来产业之城”正在加速成型。

![](20250531e10ca2451da04d15b3d7a3834efbf8bc_20250531ace020e9b9e9402abe96757c68e0cdd5.png)

  2024年10月14日，中国卫星网络集团有限公司位于雄安新区启动区的办公楼正式投入使用，这是首家注册落户雄安新区的央企。依托中国星网这样的链主企业，雄安新区开始谋划卫星互联网、时空信息、商业卫星智造、空天飞行器4大赛道，规划构建起七大细分领域并跑的空天信息产业链条。

![](20250531e10ca2451da04d15b3d7a3834efbf8bc_20250531bd560e1b36da4c9e869ae5bbac0eaec5.png)

  这样的产业布局，吸引了一家专注于商业航天和卫星互联网的高新技术企业，他们敏感地感觉到了产业发展的新机遇。

  蓝箭鸿擎（雄安）空间科技有限公司总经理 史耀中：我们主要服务国家巨型通信卫星星座的建设商，为他们提供卫星类的产品。

![](20250531e10ca2451da04d15b3d7a3834efbf8bc_20250531bb2ea1e496224d29ad0aaeea599cd66f.png)

  一款可堆叠的平板式低轨卫星是这家公司的主打产品，通过模块化设计，它可以在一枚火箭的整流罩内尽可能多地搭载卫星，从而显著降低发射成本。

![](20250531e10ca2451da04d15b3d7a3834efbf8bc_202505318913c0b27d1c40a1a0cfb14cc80391d4.png)

  今年年初这家企业正式在雄安科学园落户，现在正在争分夺秒的前期筹备中：厂房建设、人才招聘、设备订购和调试等多条任务线同步推进，确保项目在今年9月前如期启动试生产。

![](20250531e10ca2451da04d15b3d7a3834efbf8bc_2025053116dd57ae0a284024b63d080ab5bb3ad0.png)

  除了雄安新区前瞻的产业布局，让这家企业心动的，还有当地政府“真金白银”的扶持。公司落地不久，雄安科技创新成长性企业投资基金首笔8000万元资金便迅速到位。与此同时，在中试基地二期项目中，政府还为企业量身定制了高标准厂房，精准匹配卫星制造的特殊需求。

![](20250531e10ca2451da04d15b3d7a3834efbf8bc_202505315d613955a1c44dafb8ba1ca31a170578.png)

  目前，这座专用于卫星生产的定制厂房已完成结构封顶，正向着交付使用加速推进。为这家卫星制造企业量身定制的厂房仅设两层，每层层高达到13.5米，空间更为开阔，为大型设备的装配和调试留出充足余量。同时，为适配卫星的总装与转运需求，厂房两侧还特别设置了近9米高的大型卷帘门，确保整机设备可自由进出。

![](20250531e10ca2451da04d15b3d7a3834efbf8bc_20250531639c6f2c7bf34f5aac8b01733d120fae.png)

  今天的雄安新区，正在成为创新创业企业竞相涌入的沃土。自2023年8月30日雄安中关村科技园揭牌以来，已有超过1万家创新型企业完成对接。

![](20250531e10ca2451da04d15b3d7a3834efbf8bc_20250531b39287a0d04d4938ba7fb5bcc7799653.png)

  从“规划蓝图” 到 “实景铺展”，这幅徐徐展开的 “雄安画卷”，既是新时代高质量发展的生动实践，更是中国式现代化城市建设的未来样本。
