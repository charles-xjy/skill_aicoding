# 北京交通大学雄安校区A组团项目开工

2024-12-31 18:22:34 来源：_中国雄安官网_

  中国雄安官网12月31日电（李元闯）12月30日，北京交通大学雄安校区A组团项目开工动员大会在项目现场召开。北京交通大学校长余祖俊作开工动员。雄安新区党工委委员、管委会副主任，教育局党组书记、局长门扬出席大会并致辞。北京交通大学党委书记陈子季宣布项目开工，标志着北京交通大学雄安校区一期工程进入大规模建设阶段。

![](2024123134a2df0297744ea2ac9909bdb3ccae13_20241231a089869913b046d2b733ed86bca2e8cf.jpg)

开工动员大会现场。中国雄安官网李鑫 摄

![](2024123134a2df0297744ea2ac9909bdb3ccae13_20241231b5daa6a9ea0f4b62ad80e9817a90009a.jpg)

开工动员大会现场。中国雄安官网李鑫 摄

  余祖俊在开工动员讲话中向关心支持雄安校区建设的各级领导、雄安新区各有关单位和各界朋友表示诚挚的感谢。他表示，建设雄安校区是学校深入贯彻落实习近平总书记重要指示精神和党中央重大决策部署、高质量服务国家战略需求的重要举措，也是着眼学校“下一个百年发展”迈出的关键一步，将成为学校转型升级、打造未来新兴基础交叉学科的重要高地。下一步，学校将积极践行新时代高等教育的使命与担当，以更高站位、更高标准、更高要求，全力以赴建设厚重、大气、敞亮、实用的雄安校区，助力学校向世界一流大学的目标阔步前进。

  门扬对项目开工表示热烈祝贺。他指出，北京交通大学雄安校区A组团工程正式开工，标志着北京交通大学“一校多区、协同发展”进入崭新阶段。希望建设单位、施工单位和监理单位切实承担各自责任，坚守质量和安全底线，建设体现“雄安质量”和“廉洁雄安”的精品工程，确保项目2025年取得重大进展。雄安新区将全面支持北京交通大学雄安校区建设和创新发展，全力做好服务保障工作，积极助力学校以新校区建设为载体，奋力打造特色鲜明世界一流大学。

![](2024123134a2df0297744ea2ac9909bdb3ccae13_20241231771dcce0ccf140baa24e5bade8b2640f.jpg)

开工动员大会现场。中国雄安官网李鑫 摄

  据了解，北京交通大学雄安校区南区将率先启动约24万平方米建设，一期后续建设将接续展开。本次开工的A组团项目主要包括学生宿舍楼。A组团生活区以“链接”为规划理念，将居住、餐饮、运动、学习等多种功能复合，打造别开生面的中央活力学生街，营造现代大学多元共享、开放交流的生活氛围，为雄安校区未来高质量发展创造优质的育人环境。

  大会由学校党委常委、副校长李国岫主持。雄安新区有关部门负责同志，北京交通大学相关职能部门负责同志及指挥部全体人员，勘察单位、设计单位、施工单位、监理单位等200余人参加活动。
