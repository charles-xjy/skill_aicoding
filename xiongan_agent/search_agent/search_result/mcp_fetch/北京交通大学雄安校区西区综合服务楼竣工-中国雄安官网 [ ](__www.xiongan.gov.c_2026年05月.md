# 北京交通大学雄安校区西区综合服务楼竣工

2024-12-03 17:43:31 来源： _中国新闻网_

日前，北京交通大学雄安校区首个开工项目（西区综合服务楼）竣工仪式在雄安校区西区地块举行。

北京交通大学雄安校区西区综合服务楼项目占地面积约3083平方米，总建筑面积2980平方米，地上三层，地下一层，主要建设内容为办公、师生活动、后勤等综合服务用房，于2023年11月28日开工，2024年5月12日主体结构封顶，2024年11月26日竣工。

北京首批疏解到雄安新区的高校共4所，分别为北京交通大学、北京科技大学、北京林业大学、中国地质大学(北京)。其中，北京交通大学雄安校区总面积占地2600亩，计划分两期实施建设，建成后将能够满足36000名学生日常学习、科研、生活的需要。(贾梦宇 阙舟)
