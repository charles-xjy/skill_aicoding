# 多所高校将建雄安校区！雄安疏解高校有新进展

2024-06-14 17:05:42 来源： _中国雄安官网_

　　中国雄安官网6月14日电（崔利杰）日前，北京理工大学、北京航空航天大学、北京语言大学、华北电力大学、中国传媒大学5所高校官方均发布消息，将建设雄安校区，向雄安新区疏解。雄安新区非首都功能疏解工作迈上新台阶。

　　2024年年初，北京理工大学官方发布，北京理工大学全面构建“一脉五区，一体发展”的开放办学格局，雄安校区获批建设。该校主动服务并融入京津冀协同发展格局，为雄安新区科技创新、人才培养、产业布局高质量发展提供支撑。

![](1212371907_17183506341771n.png)

北京航空航天大学官网截图。

　　北京航空航天大学官网日前发布《总务部北京航空航天大学雄安校区总体规划方案征集代理服务竞价结果公示》，“官宣”了将建设雄安校区的最新消息。至此，又一所“双一流”（世界一流大学和一流学科）高校将疏解到雄安新区。

　　北京语言大学官方网站日前发布《北京语言大学雄安校区总体规划方案征集资格预审公告》，其中提到雄安校区位于雄安新区起步区第一组团，东至城市道路1-NB1，南至城市道路EB3，西至城市道路NA0，北至城市道路EB2，总用地面积47.31公顷。北京语言大学是继北京交通大学、北京科技大学、北京林业大学、中国地质大学（北京）之后又一所将疏解到雄安新区的教育部直属和“双一流”（世界一流大学和一流学科）高校。

![](1212371907_17183506396071n.png)

北京语言大学官方网站截图。

　　6月12日，华北电力大学官网发布《雄安校区（以下简称“华电雄安校区”）总体规划方案征集资格预审公告》，提及华电雄安校区位于雄安新区起步区第一组团，东至城市道路1-NB1，南至城市道路EB2，西至城市道路NA0，北至城市道路EA1。

　　6月12日，中国传媒大学官网发布《雄安校区（以下简称“中传雄安校区”）总体规划方案征集资格预审公告》，提到中传雄安校区位于雄安新区起步区第一组团，地块1东至城市道路NA2，南至城市道路EB3，西至城市道路NA1，北至城市道路EB2。地块2东至城市道路NA2，南至城市道路1-EC5，西至城市道路1-ND104，北至城市道路EB3。

　　截至目前，5所在京“双一流”高校陆续“官宣”雄安校区建设情况，预示着新一批部属高校疏解正在提速。

　　当前，雄安新区已进入大规模建设与承接北京非首都功能疏解并重阶段，工作重心已转向高质量建设、高水平管理、高质量疏解发展并举。北京交通大学雄安校区、北京科技大学雄安校区、北京林业大学雄安校区和中国地质大学（北京）雄安校区（均位于起步区第五组团）正在雄安如火如荼建设中，加上上述5所高校陆续“官宣”雄安校区建设，截至目前，已有9所疏解高校确定落地雄安。
