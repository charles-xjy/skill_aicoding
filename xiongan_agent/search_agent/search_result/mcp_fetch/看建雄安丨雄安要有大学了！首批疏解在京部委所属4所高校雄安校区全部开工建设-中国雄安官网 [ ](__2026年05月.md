# 看建雄安丨雄安要有大学了！首批疏解在京部委所属4所高校雄安校区全部开工建设

2023-11-28 11:01:25 来源： _中国雄安官网_

　　中国雄安官网11月28日电（封俊龙）今日，首批疏解的在京部委所属高校雄安校区集中开工动员会在雄安新区召开，标志着北京交通大学、北京科技大学、北京林业大学、中国地质大学（北京）等4所高校雄安校区全部开工建设。国家发改委、教育部、河北省及雄安新区、4所高校等有关方面负责同志出席动员会。

![](1212306967_17011388745231n.jpg)

中国地质大学（北京）雄安校区开工动员现场。中国雄安官网李鑫 摄

　　4所高校雄安校区开工建设，是贯彻落实党中央决策部署，推动京津冀协同发展、疏解北京非首都功能、高标准高质量建设雄安新区的重要成果。4所高校均为教育部直属、“双一流”建设高校，主要位于雄安新区起步区第五组团北部。雄安校区的建设，将显著提升学校办学条件，为学校在更高起点实现跨越式发展奠定坚实基础。同时4所高校在雄安扎根，将为雄安新区高标准高质量建设发展提供高水平教育科技人才支撑。
