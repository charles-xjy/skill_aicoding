# 设立7年，雄安新区建得咋样了？

_2024-05-25 17:47:02 来源：四川在线 编辑：梁庆_ 

_

_

四川在线记者 王代强 文/图

塔吊林立的施工现场机器声隆隆，热火朝天；碧波荡漾的白洋淀，飞鸟翔集，风景如画；干净整洁的居民小区欢声笑语，怡然自乐……夏日，四川在线记者步入河北雄安新区，感受到满满的活力、绿意和暖意。

2017年，中共中央、国务院决定设立河北雄安新区。7年来，雄安新区建得咋样了？5月22日至24日，由河北雄安新区宣传网信局主办、长城新媒体集团承办的“拔节生长向未来——2024全国重点地方媒体总编辑雄安行”主题活动举行，全国20个省(市)的35家媒体代表聚集于此，见证新区建设发展新面貌。

**未来之城：地下、地上、云上“三座城”同生共长**

雄安新区规划面积1770平方公里，包括雄县、容城县、安新县三县行政辖区(含白洋淀水域)。选择特定区域为起步区先行开发，在起步区再划出一定范围规划建设启动区，条件成熟后有序稳步推进中期发展区建设，并划定远期控制区为未来发展预留空间。

“高峰期，同时有数千台塔吊同时施工。”站在雄安东西轴线指挥调度中心观景平台，眺望雄安城际站及国贸中心片区建设现场，工作人员向记者介绍，该片区当前共有施工人员4600余人、机械设备360余套。目前，雄安城际站枢纽正进行基础底板施工和铁路站房土方开挖施工；国贸中心正进行桩基和地下主体结构施工，航站楼已冲出“正负零”。

![](https://imgcdn.scol.com.cn/media/2024/05/25/175218658429.jpg)

热火朝天的施工现场。

远处，一栋“金芦苇”造型的中国中化大厦引人注目。“建筑呼应白洋淀的淀泊自然风光，寓意生生不息、拔节生长。”工作人员介绍，这座结构高度达150米的大厦，采用了“被动优先”的建筑设计降低能耗，而光伏一体化屋面幕墙接近3600平方米，综合节能率达60%。

以创新理念推进高质量建设，雄安新区坚持先地下、后地上，数字城市与现实城市同步规划、同步建设，地下、地上、云上“三座城”同生共长，“未来之城”形象初显。

目前，雄安新区380多个重点项目累计完成投资超过6700亿元，4000多栋楼宇拔地而起。建成综合管廊约97.3公里，容东、容西片区综合管廊已投入使用，“城市大脑”雄安城市计算中心运行稳定。

同时，雄安新区作为北京非首都功能疏解集中承载地的作用进一步显现：央企在雄安设立子公司及各类分支机构200多家，首批疏解的4家央企总部建设全面提速，北京援建的3所学校和雄安宣武医院开学开诊，4所疏解高校和北京大学人民医院雄安院区开工建设，中国移动、中国联通、中国电信互联网产业园等一批市场化疏解项目加快建设……

**绿色之城：重现白洋淀“万顷波”的独特意境**

阵阵清风拂过，片片芦苇荡漾。这个时节，乘船行驶在白洋淀水面，飞翔的水鸟叫声不绝于耳，水草夹杂树木的气味扑鼻而来。踏上旅游步道，走进白洋淀最近“上新”的网红打卡地——燕南堤，可见两侧约10平方公里的水面非常开阔，随手一拍皆是美景，重现白洋淀“万顷波”的独特意境。

![](https://imgcdn.scol.com.cn/media/2024/05/25/175219178118.jpg)

燕南堤。

绿色，是雄安新区的发展底色。雄安新区设立以来，白洋淀进行了有史以来最大规模的系统性生态治理，生态环境持续改善，水质从劣Ⅴ类提升至Ⅲ类，进入全国良好湖泊行列。多年不见踪迹的鳑鲏鱼、黑鱼又重新出现，“鸟中大熊猫”青头潜鸭还在这里安了家。

![](https://imgcdn.scol.com.cn/media/2024/05/25/175219696443.jpg)

白洋淀。

雄安新区生态环境监控中心相关负责人介绍，当地通过融合全要素监测手段，建设了“天空地淀一体化智慧监测网络”，形成了以水为主的监测预警体系，实现了以数据为依据对雄安新区水质、大气现状整体把控。

夜幕降临，漫步在免费开放的悦容公园，不时遇到推着儿童车、搀扶老人的居民在此散步休闲。近年来，雄安新区持续推进千年秀林建设，已累计造林47.8万多亩，森林覆盖率由新区设立前的11%提升至34.9%，秀林、绿谷、淀湾组成的绿色空间骨架基本形成，“3公里进森林、1公里进林带、300米进公园，处处是游园”正在成为现实。

**人民之城：城市服务管理日益智能化、人性化、精准化**

“好球，好球！”5月23日上午，容西第一养老驿站内，两位老人打乒乓球，赢得阵阵喝彩。驿站1200多平方米的空间里，阅览室、书画室、休息室一应俱全，已打造成老年人“第二个家”。

雄安新区设立7年来，容东、容西、雄东等新建片区内约12万名群众喜迁新居。新城市、新社区，如何同步推进城市治理现代化？“我们一开始就下好‘绣花’功夫，推进基本公共服务均等化，构筑新时代宜业宜居的‘人民之城’。”新区相关负责人说，新区依托雄安城市计算中心等为支撑的“城市大脑”管理体系，城市服务管理日益智能化、人性化、精准化。例如，在容东片区布建约3万路前端设备，为摄像头设置19种常见场景的智能化算法，可智能识别上报各类情况，让城市“耳聪目明”，管理更加精准。

记者在容东片区南文营社区看到，步行5-10分钟范围内，集中打造了社区食堂、社区博物馆、创业空间等设施。“社区坚持党建引领，推出‘一呼联应’机制，由社区党组织牵头，整合职能部门、建设单位、小区物业等多方力量，解决群众困难。”社区党总支书记王伟肖说，依托党群服务中心，在家门口提供45项政务服务事项，打通群众办事“最后一米”。

![](https://imgcdn.scol.com.cn/media/2024/05/25/175220218334.jpg)

南文营社区。

整洁大气的校区环境、极具特色的课程设置……走进2023年9月开学的雄安史家胡同小学，现代化的办学环境令人印象深刻。该学校由北京市东城区史家胡同小学开展办学和运营，已派出“3+1”团队进驻雄安，1名北京副校长每月定期到雄安指导工作。

![](https://imgcdn.scol.com.cn/media/2024/05/25/175220675861.jpg)

雄安史家胡同小学阅览室。

据了解，紧盯就业这个“最大的民生”，雄安新区实施就业、创业、产业、物业“四业并举”，创新打造“零工驿站+职工培训学校+人力资源公司”就业培训模式，累计提供就业岗位25万个，零就业家庭动态清零。
