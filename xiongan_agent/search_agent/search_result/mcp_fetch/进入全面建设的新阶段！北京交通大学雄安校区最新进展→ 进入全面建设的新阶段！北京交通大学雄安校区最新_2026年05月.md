北京交通大学雄安校区位于雄安新区起步区第五组团北侧及启动区，一期第二组团项目位于雄安校区南区。第二组团的建设，与学校党委部署的三个重要时间节点任务密切相关，将发挥承上启下的重要作用。

第二组团项目包括思源楼、天佑会堂、实践教学媒体中心、双创及就业指导中心、南区生活配套（食堂、学习中心、综合运动中心）、校友之家、学科学院楼及公共教学楼等22栋建筑单体，约20万平方米（其中地上约14.1万平方米、地下约5.8万平方米），此外还包括相关专项及室外工程等。

![](https://imagepphcloud.thepaper.cn/pph/image/355/447/387.jpg)

雄安校区思源广场效果图。

第二组团项目建设集“学、研、文、体”多样功能，配套2个书院，设置了学习中心、文体中心、生活中心等设施，打造师生学习研究、运动交流、生活起居的300米生活圈，为师生提供全时段沟通的服务场景。南北向的学术礼仪轴，串联起学科学院楼和思源楼，与思源广场呼应，打造南区校园的核心文化空间；东西向的梧桐大道，连接东西两侧的天佑会堂及生活服务功能，传承交大学子的红果园记忆。

![](https://imagepphcloud.thepaper.cn/pph/image/355/447/388.jpg)

![](https://imagepphcloud.thepaper.cn/pph/image/355/447/389.jpg)

雄安校区南区生活配套效果图。

雄安校区思源楼位于校园南区的核心位置，总建筑面积约4.3万平方米，以“思源致远，未来之窗”为设计理念，由4根“巨柱”支撑起顶部通透的开放空间，造型方正、稳重有力，从体量大小、立面构图等方面传承学校历史文脉，延续海淀校区思源楼的形体记忆。

![](https://imagepphcloud.thepaper.cn/pph/image/355/447/390.jpg)

![](https://imagepphcloud.thepaper.cn/pph/image/355/447/391.jpg)

雄安校区思源楼效果图。

雄安校区天佑会堂位于明湖南畔，是学校举办重要会议、典礼等活动的场所，总建筑面积约1.4万平方米，观众厅坐席总数约1000座。天佑会堂以圆形的向心设计布局，轻盈简约的建筑形态结合了科技智慧与现代艺术，其出挑的屋面使建筑具有滨水建筑轻盈与开放的特征，建成后将成为“明湖之畔”的视觉焦点和承载校园文化的重要空间。

![](https://imagepphcloud.thepaper.cn/pph/image/355/447/393.jpg)

![](https://imagepphcloud.thepaper.cn/pph/image/355/447/394.jpg)

雄安校区天佑会堂效果图。

北京交通大学雄安校区一期第二组团项目预计2027年初完工，建成后将为师生提供更加舒适的学习生活环境。其中，思源楼等重要单体将于2026年9月基本完成主体结构建设，为学校130周年校庆献礼。

目前一期第一、第二组团项目建筑单体共35栋、建筑面积约44万平方米，已全部开工建设，一期第三组团项目力争于今年年底开工。

雄安新区有关部门领导，学校相关职能部门领导、雄安校区建设指挥部全体人员，施工单位、监理单位、设计单位等180余人参加活动。
