# 雄安轨道交通

播报编辑[讨论3](/planet/talk?lemmaId=21388877&fromModule=lemma_right-issue-btn)上传视频

中国河北省雄安新区境内城市轨道交通系统

雄安轨道交通是服务于中国河北省[雄安新区](/item/%E9%9B%84%E5%AE%89%E6%96%B0%E5%8C%BA/20594936?fromModule=lemma_inlink)的城市轨道交通系统，依据《[河北雄安新区规划纲要](/item/%E6%B2%B3%E5%8C%97%E9%9B%84%E5%AE%89%E6%96%B0%E5%8C%BA%E8%A7%84%E5%88%92%E7%BA%B2%E8%A6%81/22500203?fromModule=lemma_inlink)》布局，以市域快线和轨道交通普线为核心构建多层次网络，预留区域轨道通道。其首条在建线路为[雄安至北京大兴国际机场快线](/item/%E9%9B%84%E5%AE%89%E8%87%B3%E5%8C%97%E4%BA%AC%E5%A4%A7%E5%85%B4%E5%9B%BD%E9%99%85%E6%9C%BA%E5%9C%BA%E5%BF%AB%E7%BA%BF/23627922?fromModule=lemma_inlink)（R1线），全长89.55公里，设8座车站，连接雄安新区与[北京大兴国际机场](/item/%E5%8C%97%E4%BA%AC%E5%A4%A7%E5%85%B4%E5%9B%BD%E9%99%85%E6%9C%BA%E5%9C%BA/12801770?fromModule=lemma_inlink)，设计最高时速200公里，支持24小时运营并与[北京地铁大兴机场线](/item/%E5%8C%97%E4%BA%AC%E5%9C%B0%E9%93%81%E5%A4%A7%E5%85%B4%E6%9C%BA%E5%9C%BA%E7%BA%BF/23775230?fromModule=lemma_inlink)贯通 \[1-2\] \[5-6\]。

R1线于2020年10月启动建设，采用市域D型列车8辆编组，截至2024年1月仍在施工中 \[5-6\]。根据规划，雄安轨道交通远期将形成1条市域快线（含4条支线）和5条普线，总里程约219公里，覆盖起步区、雄县、容城等区域，并预留155公里轨道通道 \[3\] \[4\]。未来该系统将强化新区与北京等重点区域的交通衔接，支撑[京津冀协同发展](/item/%E4%BA%AC%E6%B4%A5%E5%86%80%E5%8D%8F%E5%90%8C%E5%8F%91%E5%B1%95/13209495?fromModule=lemma_inlink) \[8-9\]。

## 简介

播报

编辑

根据《[河北雄安新区规划纲要](/item/%E6%B2%B3%E5%8C%97%E9%9B%84%E5%AE%89%E6%96%B0%E5%8C%BA%E8%A7%84%E5%88%92%E7%BA%B2%E8%A6%81/22500203?fromModule=lemma_inlink)》，雄安新区将规划建设运行高效的城市轨道交通。按照网络化、多模式、集约型的原则，以起步区和外围组团为主体布局轨道交通网络，实现起步区与外围组团、城镇的便捷联系。根据新区建设步骤和人口规模、交通出行需求，有序建设轨道交通，对地铁作规划空间预留。加强规划控制并预留市域、区域轨道交通通道走廊空间。规划中低运量轨道交通系统，衔接大运量轨道交通。 \[3\]

[](/pic/%E9%9B%84%E5%AE%89%E8%BD%A8%E9%81%93%E4%BA%A4%E9%80%9A/21388877/0/b7003af33a87e950352ab222c1684443fbf2b2111e66?fr=lemma&fromModule=lemma_content-image "R1线线路走向")R1线线路走向

2021年6月25日，关于[雄安轨道交通R1线](/item/%E9%9B%84%E5%AE%89%E8%BD%A8%E9%81%93%E4%BA%A4%E9%80%9AR1%E7%BA%BF/63934219?fromModule=lemma_inlink)工程环境影响报告书的批复发布。 \[2\]

## 线路

播报

编辑

雄安轨道交通在建线路有[雄安至北京大兴国际机场快线](/item/%E9%9B%84%E5%AE%89%E8%87%B3%E5%8C%97%E4%BA%AC%E5%A4%A7%E5%85%B4%E5%9B%BD%E9%99%85%E6%9C%BA%E5%9C%BA%E5%BF%AB%E7%BA%BF/23627922?fromModule=lemma_inlink)（简称R1线）一条。该线路位于河北省和北京市境内，包括正线和昝岗车辆基地等工程。正线起自雄安航站楼站（含），经河北省雄安新区，河北省廊坊市的霸州市、永清县、固安县、广阳区以及北京市大兴区，止于大兴机场站（不含），并在大兴机场站预留与北京地铁大兴机场线贯通运营条件。工程全长89.55公里，包括正线86.21公里和车辆基地出入线3.34公里，其中正线河北省段长80.10公里（雄安新区段长34.87公里），北京市段长6.11公里。正线设车站8座（地下车站3座、高架车站4座、地面车站1座），新建昝岗车辆基地。正线包括高架段65.38公里，地下段19.75公里，路基及U槽段1.08公里。高架段最高运行速度200公里/小时，地下段最高运行速度160公里/小时。采用市域D型列车。 \[2\] \[5\]

雄安至北京大兴国际机场快线（简称R1线）环评公示显示，全线列车运营时间为24小时全天候。雄安轨道交通R1线建成通车后将与北京地铁大兴机场线贯通运营，实现雄安新区至北京CBD、金融街、中关村“一小时”轨道通勤便捷联系。该线路建设期为2020年10月—2023年6月底。车辆采用区域快轨D型列车，车辆编组采用8辆编组（7＋1行李车），设计运行速度高架段最高运行时速为200公里、地下段最高运行时速160公里，列车运营时间为24小时全天候。 \[1\]

雄安轨道交通R1线工程已纳入《河北雄安新区规划纲要》《河北雄安新区总体规划（2018-2035年）》和《河北雄安新区综合交通专项规划》。 \[2\]

## 规划线路

播报

编辑

雄安新区规划1条市域快线（含4条支线）和5条城市轨道交通普线。雄安新区境内规划轨道交通线网里程总长约219km，预留的轨道通道长155km。其中，起步区轨道交通线网规模约112km，预留的轨道通道长40km。 \[4\]

[](/pic/%E9%9B%84%E5%AE%89%E8%BD%A8%E9%81%93%E4%BA%A4%E9%80%9A/21388877/0/b3119313b07eca80653823a48e7b80dda144ad342562?fr=lemma&fromModule=lemma_content-image "雄安新区轨道交通线网规划示意图")雄安新区轨道交通线网规划示意图

### 快线

预留“一干多支”市域快线。该线路在雄安新区内部的规模约87km，在起步区内部的规模约30km。 \[4\]

R1线保定段

雄安轨道交通R1线的支线，规划从[保定东站](/item/%E4%BF%9D%E5%AE%9A%E4%B8%9C%E7%AB%99/7630807?fromModule=lemma_inlink)至雄安城市航站楼站。该线路正线长36km，其中高架段长17.75km，地下段长18.25km；在雄安新区内长约2km。共设5座车站。 \[4\]

R1线徐水段

R1线的支线，规划从R1线起步区一组团西侧站点引出，向西至徐水组团。该线路全长15km，其中在雄安新区内长约2km。共设1座车站。 \[4\]

R1线白沟段

R1线的支线，规划从R1线起步区五组团东侧站点引出，向北经[大河镇](/item/%E5%A4%A7%E6%B2%B3%E9%95%87/9482532?fromModule=lemma_inlink)、[晾马台乡](/item/%E6%99%BE%E9%A9%AC%E5%8F%B0%E4%B9%A1/10233111?fromModule=lemma_inlink)至白沟组团。该线路全长约22.1km，其中在雄安新区内长约12.8km。共设2座车站。 \[4\]

R1线霸州段

R1线的支线，规划从R1线雄安高铁站引出，向东北经[马庄镇](/item/%E9%A9%AC%E5%BA%84%E9%95%87/5882504?fromModule=lemma_inlink)、[牛驼镇](/item/%E7%89%9B%E9%A9%BC%E9%95%87/4014755?fromModule=lemma_inlink)、[知子营乡](/item/%E7%9F%A5%E5%AD%90%E8%90%A5%E4%B9%A1/7543821?fromModule=lemma_inlink)至北京大兴国际机场。该线路全长约51.3km，其中在雄安新区内长约12km。共设1座车站。 \[4\]

### 普线

规划5条城市轨道交通普线，布局于雄安新区内部，总规模约132km。 \[4\]

M1线

规划从起步区一组团西侧出发，向东沿东西轴依次串联起步区5个组团至第五组团东侧，与R1线共走廊继续向东经雄县组团、昝岗组团，止于雄安高铁站西侧。 \[4\]

根据线网规划，[雄安新区启动区](/item/%E9%9B%84%E5%AE%89%E6%96%B0%E5%8C%BA%E5%90%AF%E5%8A%A8%E5%8C%BA/57039270?fromModule=lemma_inlink)规划有M1线5座车站、6个区间，与M2线的换乘车站为2座。[昝岗片区](/item/%E6%98%9D%E5%B2%97%E7%89%87%E5%8C%BA/63670383?fromModule=lemma_inlink)规划M1线3站2区间：车站均位于地块内部，且与地下空间紧密结合；区间与地下环隧和地下步行通廊交织。 \[4\]

M2线

规划从容城组团西侧出发，向东贯通容城组团后向南进入起步区四组团，至东西轴后向东经过[雄安城际站](/item/%E9%9B%84%E5%AE%89%E5%9F%8E%E9%99%85%E7%AB%99/24082707?fromModule=lemma_inlink)于五组团西侧向南至安新组团，止于安新组团南部。 \[4\]

根据线网规划，启动区规划有M2线6座车站、5个区间，与M1线的换乘车站为2座。[容东片区](/item/%E5%AE%B9%E4%B8%9C%E7%89%87%E5%8C%BA/55471822?fromModule=lemma_inlink)规划有轨道交通M2线，在该片区内部呈倒“L”型走向，采用地下敷设方式；共设置3座车站，分别为八于站、南文站和容南站，其中八于站、南文站2座车站为远景换乘站。 \[4\]

M3线

规划从起步区一组团南侧出发，向北贯通一组团后向东，东西向贯通起步区北侧发展走廊至起步区五组团东侧，止于R1线白沟段换乘站东侧。 \[4\]

根据线网规划，启动区规划有M3线6座车站、5个区间，与M2线的换乘车站为1座；M3线支线3座车站、3个区间，与M3线的换乘车站为1座。 \[4\]

M4线

规划从贾光镇出发，向南串联[白洋淀站](/item/%E7%99%BD%E6%B4%8B%E6%B7%80%E7%AB%99/16519112?fromModule=lemma_inlink)，经容城组团中部贯通起步区二组团后，向西南经一组团南部与M3线换乘，向西至寨里组团，止于寨里组团。 \[4\]

M5线

规划从[白沟站](/item/%E7%99%BD%E6%B2%9F%E7%AB%99/16687700?fromModule=lemma_inlink)西侧出发，与R1线白沟段交汇后向西，经[刘合庄村](/item/%E5%88%98%E5%90%88%E5%BA%84%E6%9D%91/4079948?fromModule=lemma_inlink)向南，与M2线换乘向西，经小里站转向西南，止于寨里组团。 \[4\]

根据线网规划，容东片区内远景规划预留轨道交通M5线，在与M2线共走廊段设置2座车站，其余非共走廊设置2座车站。该片区内M5线均采用地下敷设方式。 \[4\]
