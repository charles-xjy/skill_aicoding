为您精选了几家上海陆家嘴附近口碑极佳的本帮菜餐厅，兼顾地道口味与用餐体验：

1. **人和馆（浦东嘉里城店）**
   - **特色**：以“红烧肉”闻名，肉质酥烂入味，酱汁浓郁。还有葱烤大排、响油鳝丝等经典菜品，环境古朴雅致，很有老上海风情。
   - **位置**：位于陆家嘴核心区，交通非常便利。

2. **福和慧（虽非纯本帮，但值得提及）**
   - *注：如果您追求顶级高端体验，可考虑这家米其林二星素食，但非传统本帮。若坚持传统本帮，推荐以下家：*

3. **兰心餐厅（陆家嘴中心店附近或附近分店）**
   - **特色**：性价比高，分量足，是本地人也爱去的“苍蝇馆子”升级版。推荐蟹粉豆腐、四喜烤麸、草头圈子，味道正宗且价格亲民。

4. **老正兴（外滩店，稍远但经典）**
   - **特色**：中华老字号，以海派本帮菜著称，尤其是草头圈子（大肠配苜蓿芽）和八宝鸭，历史底蕴深厚。
   - **提示**：距离陆家嘴步行稍远，建议打车前往，适合对“老字号”有情怀的旅客。

5. **新荣记（如果预算充足）**
   - **特色**：虽然主打台州菜，但在上海极为受欢迎，部分菜品如糟粕醋火锅、黄金脆带鱼等，口味细腻精致，服务顶级，适合商务宴请或追求高品质用餐体验。

**建议**：
- 本帮菜口味偏甜浓油赤酱，若不习惯可提前告知服务员调整。
- 陆家嘴用餐高峰（周末及工作日晚市）人多，建议提前通过大众点评或电话预订位置。
- 如需最新营业时间及排队情况，建议出发前查看实时地图软件信息。
