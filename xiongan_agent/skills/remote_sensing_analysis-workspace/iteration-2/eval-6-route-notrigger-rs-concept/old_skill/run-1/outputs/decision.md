光学遥感和雷达遥感的区别主要体现在成像原理、数据特性及应用场景上：

1.  **成像原理**：
    *   **光学遥感**：被动遥感，依赖太阳光或其他自然光源照射地面物体后反射的能量进行成像。
    *   **雷达遥感**：主动遥感，传感器自身发射微波信号，接收地面目标反射的回波信号进行成像，不依赖自然光照。

2.  **主要区别**：
    *   **受天气影响**：光学遥感易受云、雾、雨、雪等大气条件影响，难以穿透云层；雷达遥感具有穿透性，受云雨影响小，可实现全天候观测。
    *   **观测时间**：光学遥感只能在白天（有光照时）工作；雷达遥感可昼夜连续工作。
    *   **信息维度**：光学主要提供颜色和纹理信息；雷达提供后向散射系数、极化、干涉相位等信息，能反映地物的介电常数和表面粗糙度。

3.  **空间分辨率是否越高越好？**
    **不一定。** 虽然高分辨率能提供更详细的地物信息，但也带来以下权衡：
    *   **成本增加**：分辨率越高，卫星造价、数据存储、传输和处理成本通常越高。
    *   **覆盖范围受限**：高分辨率传感器的视场通常较窄，覆盖相同面积所需时间长或需多次观测。
    *   **应用需求匹配**：如果目标是监测大范围的城市扩张、土地利用变化或宏观气候变化，中低分辨率数据往往更高效且足够使用。只有在需要识别小目标（如车辆、小型建筑细节）时，才需要极高分辨率。
    *   **“合适”才是最佳**：选择分辨率应根据具体任务需求、预算和时效性要求综合决定。
