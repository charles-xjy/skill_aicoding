雄安新区的规划体系与政策文件体系庞大且严谨，主要遵循“规划引领、制度先行”的原则。以下为您梳理的核心总体规划框架及关键政策文件：

### 一、 总体规划体系

雄安新区的规划遵循“1+1+3”+“X”的规划体系：

1.  **《河北雄安新区规划纲要》**（核心总纲）
    *   **地位**：雄安新区发展的顶层设计和宏观蓝图。
    *   **核心内容**：明确了雄安新区的战略定位（绿色生态宜居新城区、创新驱动发展引领区、协调发展示范区、开放发展先行区）；提出了“1963”平方公里的规划范围（起步区300平方公里，中期发展区200平方公里，远期控制区163平方公里）；确立了“白洋淀生态优先”、“地下空间统筹”、“组团式发展”等核心原则。

2.  **《河北雄安新区总体规划（2018-2035年）》**（详细执行规划）
    *   **地位**：落实《规划纲要》的具体空间布局和实施依据。
    *   **核心内容**：详细规定了“一核、三区、多组团”的空间结构；明确了基础设施、公共服务设施、生态环境建设的具体指标和时序；强调了“多规合一”，将土地利用规划、城乡规划、生态保护规划等整合。

3.  **专项规划（“3”类专项规划）**
    *   **起步区控制性详细规划**：针对起步区（300平方公里）的详细管控。
    *   **起步区起步阶段发展规划**：针对初期建设的重点项目和时序安排。
    *   **白洋淀生态环境治理和保护规划**：专门针对白洋淀水环境综合治理、生态修复的规划。
    *   *注：随着发展，还衍生出了交通、市政、地下空间、创新平台等多个专项规划。*

### 二、 主要政策文件体系

雄安新区的政策以“改革”为特色，建立了相对独立于传统地级市的体制机制。主要政策可分为以下几类：

#### 1. 顶层设计与体制机制
*   **《中共中央 国务院关于支持河北雄安新区全面深化改革和扩大开放的指导意见》**
    *   这是雄安新区改革的行动指南，提出了30余项重大改革举措，包括户籍、土地、金融、人才等。
*   **《河北雄安新区条例》**（地方性法规）
    *   2022年10月通过，2023年1月1日施行。这是雄安新区第一部综合性地方法规，从法律层面确认了新区的管理体制、规划建设、产业发展、生态环境等内容。

#### 2. 土地与住房保障
*   **《河北雄安新区土地使用权出让管理办法》**
    *   创新土地供应方式，如“带方案出让”、“标准地”出让等。
*   **《关于建立健全雄安新区住房供应和保障体系的意见》**
    *   提出“租购并举、先租后售、租购同权”的住房制度，建立多主体供给、多渠道保障、租购并举的住房制度。

#### 3. 产业与创新
*   **《河北雄安新区战略性新兴产业集聚区发展规划》**
    *   聚焦新一代信息技术、新材料、生物医药、空天信息、节能环保等未来产业。
*   **《关于鼓励和支持社会资本参与雄安新区建设运营的指导意见》**
    *   鼓励PPP（政府和社会资本合作）模式参与新区基础设施建设。

#### 4. 生态与环境
*   **《白洋淀生态环境治理和保护规划》**
    *   设定了具体的水质目标（如全面消除劣V类水体）和生态修复任务。
*   **《雄安新区绿色建筑发展三年行动计划》**
    *   强制推行绿色建筑标准，要求新建建筑全面执行绿色建筑标准。

#### 5. 公共服务与民生
*   **《雄安新区公共服务配套规划》**
    *   引入北京优质教育、医疗资源（如北京四中、宣武医院等在雄安设立分校/分院）。
*   **《雄安新区人才引进与培养政策》**
    *   提供住房补贴、子女入学、医疗绿色通道等优惠措施。

### 三、 核心规划理念总结

1.  **生态优先**：以白洋淀生态保护为前提，蓝绿空间占比稳定在70%左右。
2.  **以人为本**：打造“15分钟生活圈”，强调公共服务均等化。
3.  **地下空间统筹**：建立综合管廊体系，实现“管道地下走、交通分层建”。
4.  **数字孪生**：同步建设数字雄安新区，实现物理城市与数字城市虚实映射。
5.  **交通绿色**：构建“三纵两横”高速铁路网，内部交通以公共交通和慢行系统为主。

这些文件和规划共同构成了雄安新区发展的法律、政策和空间基础，确保了其作为“千年大计”的高起点规划和高标准建设。如需查阅具体文件全文，建议访问**河北雄安新区官网**或**中华人民共和国中央人民政府网站**的专题专栏。
