2022年北京冬奥会主要在三个赛区举行，共使用了25个场馆，具体分布如下：

1.  **北京赛区**：主要负责冰上项目。
    *   国家游泳中心（“水立方”，冬奥会期间转换为“冰立方”用于冰壶比赛）
    *   国家体育馆
    *   五棵松体育中心（冬奥会期间称为“五棵松冰上运动中心”）
    *   首都体育馆

2.  **延庆赛区**：主要负责高山滑雪、雪车、雪橇等雪上项目。
    *   国家高山滑雪中心
    *   国家雪车雪橇中心（“雪游龙”）
    *   延庆冬奥村

3.  **张家口赛区（位于河北省张家口市）**：主要负责越野滑雪、跳台滑雪、北欧两项、冬季两项等雪上项目。
    *   国家越野滑雪中心
    *   国家跳台滑雪中心（“雪如意”）
    *   云顶滑雪公园
    *   张家口冬奥村
    *   国家冬季两项中心

开幕式和闭幕式则在**国家体育场**（“鸟巢”）举行，该场馆也位于北京赛区。
