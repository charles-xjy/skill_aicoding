上海陆家嘴及周边有不少评价不错的本帮菜馆子，以下为您推荐几家不同风格的餐厅：

1. **上海老饭店（豫园店）**
   - 虽然不在陆家嘴核心区，但距离不远（打车约15-20分钟），是正宗的本帮菜老字号。
   - **特色**：油爆虾、八宝鸭、草头圈子，口味传统浓郁。
   - **适合**：想要体验最经典上海味道，且愿意稍微跑远一点的商务宴请。

2. **甬府（陆家嘴中心L型广场店/国金中心店）**
   - 定位中高端，环境优雅，适合商务招待。
   - **特色**：主打甬帮菜（宁波菜，上海人非常喜爱），招牌菜包括蟹粉豆腐、红膏呛蟹、黄鱼汤等，服务细致。
   - **注意**：需要提前预订，排队较久。

3. **人和馆**
   - 隐藏在老洋房或特色建筑中（部分分店靠近浦东或黄浦交界），环境极具海派风情。
   - **特色**：精致本帮菜，如熏鱼、红烧肉、响油鳝糊，摆盘讲究，口味偏甜润。
   - **适合**：喜欢氛围感、注重用餐环境的食客。

4. **苏浙汇（陆家嘴店）**
   - 经典连锁，品质稳定，交通便利。
   - **特色**：融合江浙口味，本帮菜和杭帮菜都有，如松鼠鳜鱼、东坡肉、蟹粉狮子头。
   - **适合**：稳妥之选，不容易出错，适合快速用餐或小型聚会。

5. **兰心餐厅（近陆家嘴）**
   - 本地人常去的小馆子，性价比高。
   - **特色**：家常本帮味，如糖醋小排、炒素菜、腌笃鲜，味道地道。
   - **适合**：工作餐或想体验市井气息的出差人士。

**温馨提示：**
- 本帮菜普遍偏甜，如有忌口可提前告知服务员。
- 陆家嘴地区餐饮竞争激烈，周末或饭点高峰建议务必提前电话预订。
- 如需更精准推荐，可告知您的预算范围和用餐人数。
